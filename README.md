
# Failed Login Heatmap Generator

## Project Overview
This project analyzes failed authentication attempts from a mock Linux authentication log and visualizes when failed login activity is highest.

The Python script extracts timestamps from failed login entries, groups the attempts by date and hour, and generates a heatmap using Matplotlib. It also identifies the three hours with the highest number of failed login attempts.

## Objective
The goal of this project is to practice:
- Security log analysis
- Log parsing with Python
- Datetime handling
- Data aggregation
- Security data visualization

## Technologies
- Python
- Matplotlib
- Linux authentication logs
